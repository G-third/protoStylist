About proto/Stylist

proto/Stylist is a design system prototyping workbench. It allows product designers to dynamically customise and preview design tokens (typography, colours, spacing, curves, borders) and UI component styles in real time.

Core Features

  • Start configuring variables under Baseline Styles to establish typography and colour scales.
  • Move down to Controls & Input and Components to refine component styles.
  • Toggle the Code tab inside the preview area to copy clean HTML layouts or Web Components.

Export Functions

  • Export CSS: Downloads standard CSS custom properties (tokens) and component utility classes for inclusion in web projects.
  • Export JS: Exports the active configuration logic and component registration scripts for programmatic runtime theme injection.
  • Export JSON: Saves the complete configuration schema as a shareable file, allowing you to back up and restore your design sessions.

Proof of Concept Note: This is a client side proof of concept with no persistent server backend database. All styling sessions are saved using local storage in your browser. Since local storage can be wiped by cache cleaning, it is highly recommended to export your configurations as JSON files to preserve your work.
